# Java Logical Coding Practice

A collection of Java programming exercises and logical coding challenges focused on improving problem-solving skills and strengthening Core Java concepts.

This repository contains hands-on Java programs covering arrays, strings, number operations, collections, searching, sorting, and other programming challenges.

## Topics Covered

### 1. Array Programs
- Binary Search
- Reverse an Array
- Find Duplicate Elements
- Find Missing Numbers
- Find Majority Element
- Find Second Largest Element
- Move All Zeros to the End
- Find Pairs with a Given Sum
- ArrayList Operations

### 2. String Programs
- Check Palindrome
- Find All Substrings
- Find Longest Substring
- Find First Non-Repeating Character
- Count Character Occurrences
- Remove Duplicate Characters
- Reverse Words in a String
- Check String Rotation
- String Compression
- Sort Characters in a String

### 3. Number Operations
- Prime Number Check
- Fibonacci Series
- Reverse a Number
- Sum of Digits
- Count Digits
- Check Leap Year
- Find Largest of Three Numbers
- Swap Two Numbers
- Generate Random Numbers

### 4. Collections
- HashMap Iteration Techniques
- Sort HashMap by Keys
- ArrayList Operations
- HashSet Usage
- Stack Operations

### 5. Pattern Programs
- Star Pattern Printing

## Technologies Used

- Java
- JDK
- Java Collections Framework
- Eclipse IDE

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Sunilmaske12/Java-Logical-Coding-Practice.git
   ```

2. Import the `JavaChallenges2` project into Eclipse as an existing Java project.

3. Navigate to the required package and open the Java program.

4. Run the class containing the `main()` method.

Alternatively, compile and run individual Java classes using the Java compiler and runtime.

## Purpose

This repository is maintained as a collection of Java programming exercises to improve logical thinking, understand common programming problems, and strengthen problem-solving skills useful for Java development and technical interviews.
